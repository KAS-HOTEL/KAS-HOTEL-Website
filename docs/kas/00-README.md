|---|---|---|

```
KAS_TEST_DB_MIGRATE=dry-run ./mvnw test -Dtest=IntegrationDatabaseMigration -DfailIfNoSpecifiedTests=false

```

`apply` also loads `src/test/resources/db/test-fixtures/owner-settings.sql`, the test-only values of the five owner-answered settings (docs 99, 117, 132).
