# KAS Hotel V17.6 — Complete Vietnamese Hotel Detail

## Scope
- Adds Vietnamese translations for hotel detail pages and dynamically rendered room/property data.
- Keeps the selected language persistent across internal navigation.
- Saved language preference takes priority over stale `?lang=` values on later pages.
- Translates hotel taglines, full hotel descriptions, addresses/area labels, amenities, room names, bed/view/bathroom details, room notes, payment text, policies, review labels and available guest-review text.
- Keeps proper hotel/brand names, source names, ratings and URLs unchanged where they are proper nouns or source references.

## Uploads
The `uploads/` directory is intentionally excluded from the ZIP. Keep the existing persistent `uploads` directory on the local/Render environment.
