# Tài liệu và log frontend cũ

Các file ở đây được chuyển từ thư mục gốc `frontend/` ngày 24/10/2026 để giữ lại lịch sử đối chiếu admin V22. Không xóa tài liệu, ảnh hoặc dữ liệu vận hành.

- `MOVED-FILES.txt` ghi đường dẫn cũ và mới của từng file.
- Các đường dẫn tương đối trong ghi chú cũ được hiểu theo vị trí gốc trong `frontend/`.
- `frontend/admin.html`, `frontend/js/admin.js`, `frontend/server.js`, dữ liệu JSON và `uploads/` vẫn được giữ tại chỗ. Chỉ gỡ admin cũ sau khi đối chiếu dữ liệu ảnh và giá trong một công việc riêng.
- Cấu trúc Next.js đang dùng nằm trong `frontend/src/`. Tài liệu triển khai hiện tại: [kết quả chuyển đổi admin](../kas/155-admin-console-migration.md).
